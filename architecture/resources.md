# Ресурсы игры

Ресурсы разделены на три этапа прогрессии. Внутри каждого этапа они сгруппированы по назначению.

## Начальные ресурсы

Базовые материалы и запасы для производственных цепочек. Используются в производстве и снабжении; планеты их не принимают.

| Категория | Ресурсы |
| --- | --- |
| Еда для работников | Зерно |
| Топливо для пушки | Твёрдое топливо |
| Металлы для цехов | Металлолом |
| Компоненты автоматики | Механические детали |
| Вода и охлаждение | Вода |
| Медицина | Лекарственные травы |
| Кристаллы и реакторные компоненты | Необработанные кристаллы |
| Упаковка и тара | Пустые контейнеры |
| Навигация и данные | Обломки зондов |
| Удобрения для ферм | Органические отходы |
| Энергия для производства | Аккумуляторы |

## Средние ресурсы

Изготовленные товары для снабжения работников, развития цехов и торговли с первыми планетами. В заказах планет 1–50 используются ресурсы этого этапа.

| Категория | Ресурсы |
| --- | --- |
| Еда для работников | Сухие пайки; Консервы; Тепличные овощи |
| Топливо для пушки | Пороховые заряды; Ракетное топливо; Криогенное топливо |
| Металлы для цехов | Стальные балки; Титановые пластины; Медный провод |
| Компоненты автоматики | Электродвигатели; Печатные платы; Промышленные датчики |
| Вода и охлаждение | Техническая вода; Жидкий азот; Смазочно-охлаждающая жидкость |
| Медицина | Бинты; Антибиотики; Обезболивающие |
| Упаковка и тара | Грузовые поддоны; Упаковочная плёнка; Герметичные контейнеры |
| Удобрения для ферм | Минеральные удобрения; Компост; Питательный раствор |

## Поздние ресурсы

Сложные товары для дальней прогрессии: высокотехнологичное производство, мощная энергетика и дальняя навигация. Появляются в заказах начиная с планеты 51; средние ресурсы также остаются востребованными.

| Категория | Ресурсы |
| --- | --- |
| Еда для работников | Питательные концентраты |
| Топливо для пушки | Плазменные заряды |
| Металлы для цехов | Вольфрамовые стержни |
| Компоненты автоматики | Квантовые контроллеры |
| Вода и охлаждение | Криогенный хладагент |
| Медицина | Медицинские нанороботы |
| Кристаллы и реакторные компоненты | Энергетические кристаллы; Термоядерные элементы; Капсулы антиматерии; Реакторные ядра |
| Упаковка и тара | Контейнеры с радиационной защитой |
| Навигация и данные | Звёздные карты; Навигационные чипы; Координаты гиперпереходов; Архивы экспедиций |
