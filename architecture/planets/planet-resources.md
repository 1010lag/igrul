# Ресурсы, которые принимают планеты

Планеты принимают только изготовленные ресурсы из разделов «Средние ресурсы» и «Поздние ресурсы» в [списке ресурсов](../resources.md). Начальные ресурсы не принимаются.

- Планеты 1–25: 2 ресурса среднего этапа, простые товары.
- Планеты 26–50: 3 ресурса среднего этапа.
- Планеты 51–75: 3 ресурса; появляются поздние товары, включая энергетические кристаллы и навигационные чипы.
- Планеты 76–100: 4 ресурса среднего и позднего этапов.
